# nextword_prediction
# Next Word Prediction Using GRU

## About the Project
This project predicts the next possible word based on the words entered by the user using Deep Learning.

## Technologies Used
- Python
- Google Colab
- TensorFlow / Keras
- NumPy
- Scikit-learn
- NLTK

## Model Used
GRU (Gated Recurrent Unit)

## Dataset
The project uses a text dataset containing 18,000 sentences.

## Workflow
1. Upload the text dataset.
2. Preprocess the sentences.
3. Convert words into numerical sequences.
4. Split the dataset into training and testing data.
5. Train the GRU model.
6. Evaluate the model accuracy.
7. Predict the next possible words.

## Results
- Top-1 Accuracy: 46.70%
- Top-5 Accuracy: 63.71%

## How to Run
1. Open the notebook in Google Colab.
2. Upload the text dataset when prompted.
3. Run all cells in order.
4. Enter a sentence to predict the next possible words.

## Future Improvements
- Use a larger and more diverse dataset.
- Tune model parameters.
- Improve prediction accuracy.

## Conclusion
This project demonstrates how deep learning can be used to predict the next word in a sentence.
